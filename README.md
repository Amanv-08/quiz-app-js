# 📝 JavaScript Quiz App

A simple and interactive quiz application built using **HTML, CSS, and JavaScript**. This project allows users to answer multiple-choice questions about web development and view their final score at the end of the quiz.

## 🚀 Features

- Multiple-choice questions with four options.
- Instant feedback for correct and incorrect answers.
- Highlights the correct answer in green and incorrect answers in red.
- Disables all answer buttons after selecting an answer.
- Tracks the user's score.
- Displays the final score after completing the quiz.
- Allows users to restart the quiz using the Play Again button.

## 🛠️ Technologies Used

- **HTML5** - Structure of the application.
- **CSS3** - Styling and layout.
- **JavaScript** - Quiz logic, answer validation, score tracking, and navigation.

## ⚙️ How to Run the Project

1. Clone the repository:

   ```bash
   git clone https://github.com/Amanv-08/quiz-app-js.git
   ```

2. Navigate to the project directory:

   ```bash
   cd quiz-js
   ```

3. Open the `index.html` file in your web browser.

4. Select an answer for each question and click **Next** to continue.

5. View your final score and click **Play Again** to restart the quiz.

## 🎮 How to Play

1. Start the quiz and read the question.
2. Choose one of the four available answers.
3. View the feedback to check whether your answer is correct.
4. Click the **Next** button to move to the next question.
5. After answering all questions, view your final score.
6. Click **Play Again** to try again.
